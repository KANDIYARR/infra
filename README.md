# Infra Solutions Static Website

This package recreates the supplied homepage as a responsive static website.

## Preview
Extract the ZIP, then run:

```bash
cd infra_solutions_static_site
python3 -m http.server 8080
```

Open `http://localhost:8080`.

## Included
- Responsive HTML/CSS/JavaScript
- Animated hero background
- Sticky navigation and mobile menu
- Scroll reveal animations
- Animated counters
- Hover/3D service cards
- Custom SVG logo, icons, flag, map and Tanzanian geometric pattern
- Locally stored image assets derived from the supplied design reference

## Before publishing
Replace the placeholder contact details, performance figures, project statistics and company claims with verified information.
